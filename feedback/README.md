# Фідбек Славіка

Славік нічого не розмічає значками. Бот дає новини й ставить короткі питання («чому беремо?», «чому ні?», «де твій досвід?»), Славік відповідає голосом або текстом.

**Файл на кожен випуск:** `ДАТА_MN№_research.md` (наприклад, `2026-11-18_MN14_research.md`).
**Рядок:** новина · рішення (беремо / ні / під питанням) · причина словами Славіка · джерело · кластер.
Бот структурує, але нічого не додає від себе.

**Після випуску:** розбір «план → фінал Славіка» окремим файлом (зразок — `2026-11-11_MN13_final.md`).
