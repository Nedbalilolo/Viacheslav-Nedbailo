# Бот «Молоді Новини» — цифровий помічник Славіка

**Що це за папка (репозиторій)?** Це «пам'ять» бота на GitHub — як Google Drive-папка, але з історією кожної зміни. Бот щотижня прокидається «з чистою головою», читає звідси свої правила, стоп-лист і джерела, робить дайджест і кладе його сюди + у Google Doc.

**Як почати новий чат:** див. `system/RETRO_2026-11-11.md`, розділ 6.

## Що де лежить
- `CLAUDE.md` — головні правила бота (конституція).
- `context/` — хто ми, стоп-лист рубрики, Editorial DNA, патерни сценаріїв.
- `sources/` — реєстр джерел, кандидати, «здоров'я» джерел, ручний перегляд.
- `digests/` — дайджести по датах.
- `feedback/` — відповіді Славіка по новинах і розбори «план → фінал».
- `system/` — журнал змін і вивчені правила.

## Як працює цикл (CLAUDE.md, розділ 5а)
1. **Дослідження.** Бот перевіряє доступ до всіх джерел і одним списком каже, чого бракує. Далі дослідження: значки 🟢 / 🟡 / 🔴 біля фактів, джерела списком унизу, у кінці — «Беремо / Не беремо / Під питанням» і короткі питання Славіку.
2. **Фідбек.** Славік голосом пояснює, що беремо і чому. Бот зберігає це у `feedback/` без власних доповнень.
3. **План сценарію.** Тільки те, що Славік залишив. Без значків і міток, лише ❗ для точних цифр; джерела внизу.
4. **Фінальний текст.** Славік питає, де глибше, — бот доопрацьовує. Особистий досвід — питає, не вигадує.
5. **Після випуску.** Оновлення стоп-листа і розбір «план → фінал Славіка».

Зміни правил — лише після «так» Славіка (запис у `system/changelog.md`).
