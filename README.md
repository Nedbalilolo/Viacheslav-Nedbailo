## Що де лежить
- `CLAUDE.md` — головні правила бота (конституція).
- `context/` — хто ми, стоп-лист, беклог відкладених тем, Editorial DNA, патерни сценаріїв.
- `sources/` — реєстр джерел (з лічильником «у фіналі»), кандидати, доступ і «здоров'я» джерел, ручний перегляд.
- `reports/` — дослідження етапу 1 · `scenarios/` — плани й фінали · `digests/` — тижневі дайджести.
- `feedback/` — відповіді Славіка по новинах і розбори «план → фінал».
- `system/` — журнал змін, вивчені правила, відкриті рішення (`open_items.md`), ретро.

## Як працює цикл (CLAUDE.md, розділ 5а)
0. **Перше повідомлення циклу** (на один екран): вертикалі джерел, нові кандидати, доступи, календар, беклог, «досі висить». Не більше 5 рішень за раз.
1. **Дослідження** (до 15 новин): значки 🟢 / 🟡 / 🔴, джерела списком унизу, «Беремо / Не беремо / Під питанням», короткі питання Славіку → `reports/`.
2. **Фідбек.** Славік голосом пояснює, що беремо і чому → `feedback/ДАТА_MN№_research.md`, без доповнень бота.
3. **План сценарію.** Тільки те, що Славік залишив; лише ❗ для точних цифр → `scenarios/`.
4. **Фінальний текст.** Славік питає, де глибше; особистий досвід — питати, не вигадувати → `scenarios/`.
5. **Після випуску.** Стоп-лист, розбір «план → фінал», беклог, лічильник джерел у реєстрі.

Зміни правил — лише після «так» Славіка (запис у `system/changelog.md`).
