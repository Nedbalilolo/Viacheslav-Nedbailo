# Бот «Молоді Новини» — цифровий помічник Славіка

**Що це за папка (репозиторій)?** Це «пам'ять» бота на GitHub — як Google Drive-папка, але з історією кожної зміни. Бот щотижня прокидається «з чистою головою», читає звідси свої правила, стоп-лист і джерела, робить дайджест і кладе його сюди + у Google Doc.

**Як почати новий чат:** див. `system/RETRO_2026-11-11.md`, розділ 6.

## Що де лежить
- `CLAUDE.md` — головні правила бота (конституція).
- `context/` — хто ми, стоп-лист рубрики, Editorial DNA, патерни сценаріїв.
- `sources/` — реєстр джерел, кандидати, «здоров'я» джерел, ручний перегляд.
- `digests/` — дайджести по датах.
- `feedback/` — розмітка Славіка (🎬/📱/❌/📌).
- `system/` — журнал змін і вивчені правила.

## Як працює цикл
1. Понеділок: бот збирає новини за 7 днів → дайджест (Google Doc + `digests/`).
2. Славік розмічає тези.
3. Бот записує розмітку в `feedback/`, рахує корисність джерел і пропонує покращення.
4. Зміни правил і джерел — лише після «так» Славіка (запис у `system/changelog.md`).
