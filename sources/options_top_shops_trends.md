# Варіанти: топ-магазини й категорії Etsy без експорту eRank + Trend Hunter + Google Trends

Стан: на виборі Славіка. Нічого не впроваджено. Перевірки доступу — 11.11.2026, з хмарної сесії.

## 1. Топ-магазини й категорії Etsy

**А. Etsy Open API v3 (офіційний, безкоштовний)**
- Можливо: за списком відомих магазинів щомісяця брати лічильник продажів магазину й рахувати приріст за місяць; шукати активні лістинги за ключовими словами й бачити кількість «улюблених».
- Неможливо: отримати готовий рейтинг «топ-10 Etsy» — API не дає глобального списку, потрібен стартовий список магазинів (наприклад, топ у ваших нішах).
- Що потрібно від тебе: зареєструвати застосунок на etsy.com/developers (сторінка відкривається) і дати ключ через захищену форму.
- Не впевнений: які саме поля API зараз віддає (лічильник продажів — за моєю пам'яттю, не перевіряв), ліміти запитів і чи швидко Etsy схвалює особистий застосунок. API без ключа відповідає 403 — це очікувано.

**Б. Koalanda (статистика Etsy по країнах)**
- Можливо: сайт відкривається напряму. Публікує статистику по країнах, зокрема Україні, і топи магазинів.
- Неможливо: перевірити методологію — це оцінки третьої сторони, рівень довіри 🔴.
- Не впевнений: які дані віддаються без підписки.

**В. Офіційні звіти Etsy (раз на квартал)**
- Можливо: категорійні сигнали з квартальних листів і дзвінків (подарунки, весілля, персоналізація) і частки категорій з річного звіту (лютий).
- Неможливо: щомісячний ритм і топ-магазини.

**Г. Публічні рейтинги третіх сторін (InsightAgent, EtsyHunt тощо)**
- Можливо: читати через пошук.
- Неможливо: довіряти цифрам — методологію не розкривають, раніше суперечили одне одному. Рівень 🔴, лише як підказка.

**Д. Збір з публічних сторінок Etsy (лічильник продажів на сторінці магазину)**
- Технічно: etsy.com блокує ботів (403). Через браузер у хмарі теж, імовірно, заблокує.
- Не раджу: порушує правила Etsy щодо автоматичного збору.

**Моя рекомендація:** В як основа (надійно, раз на квартал) + А як щомісячний трекер для 20–30 магазинів у ваших нішах. Б — як додатковий сигнал з позначкою 🔴.

## 2. Trend Hunter
**Рішення Славіка (11.11.2026): ручний перегляд раз на квартал, бот нагадує (лютий, травень, серпень, листопад). Нижче — історія аналізу.**
- Перевірка: головна сторінка й RSS відповідають 403 «Access denied» — сайт блокує ботів.
- Можливо: читати окремі статті через пошук (переказ).
- Неможливо: системний моніторинг без ручного доступу; платні звіти недоступні.
- Чесно: у #13 Trend Hunter не дав жодної новини. Тематика — споживчі новинки, а не handmade; для «Молодих Новин» цінність сумнівна. Пропоную статус «прибране» або перевірка раз на квартал вручну тобою.

## 3. Google Trends
- Перевірка: RSS «трендів дня» (trends.google.com/trending/rss?geo=US) відкривається, але там загальні теми — спорт, новини, не товари. Сторінка порівняння запитів відповідає 429 — Google обмежує автоматичні запити.
- Неофіційна бібліотека pytrends встановлюється, але зазвичай впирається в той самий 429. Не впевнений, що вона стабільно працюватиме з хмари.
- Офіційне API Google Trends: за моєю пам'яттю, у 2025 Google відкрив закрите альфа-тестування за заявками. Не перевіряв, чи доступне зараз.
- Платні обхідні шляхи: SerpApi (Google Trends через API, потрібен ключ і оплата), Glimpse (уже в реєстрі, платно).
- Що реально можна без витрат: точково перевіряти 5–10 запитів під випуск (наприклад, «personalized gift», «pet ornament») через пошук або вручну тобою на trends.google.com і давати скрін.

**Моя рекомендація:** для старту — ручна точкова перевірка під конкретні теми випуску. Якщо захочеш автоматизувати — SerpApi з ключем (платно) або заявка на офіційне API.
