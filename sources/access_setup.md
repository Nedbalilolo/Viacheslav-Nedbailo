## TELEGRAM — інструкція
1. Telegram Desktop (на комп'ютері; у телефоні експорту немає) → відкрити чат.
2. ⋮ (три крапки вгорі справа) → Export chat history.
3. Зняти всі галочки з фото, відео, файлів — лишити лише текст. Формат: **Machine-readable JSON**. Період: останні 7 днів.
4. Отриманий файл `result.json` перейменувати: `EtsyBiznes_2026-11-17.json` (назва чату + дата експорту).
5. Покласти в Drive-папку «Молоді Новини — бот / Telegram».
6. Як часто: раз на тиждень, у понеділок до запуску бота. Обидва чати — два файли.

## ETSY OPEN API — інструкція
1. Увійти на Etsy під акаунтом продавця → https://www.etsy.com/developers/register
2. Створити застосунок: назва (наприклад, «MB Market Monitor»), опис «Internal analytics of public shop statistics», сайт — molodybiz.com. На питання про комерційне використання — відповідати чесно: внутрішня аналітика. Точні назви полів форми я не бачив — можуть відрізнятися.
3. Після створення: Your Account → Apps You've Made → у застосунку видно **keystring** і **shared secret**.
4. Ключ НЕ надсилати в чат. Скажи «ключ готовий» — бот покаже захищену форму для сайту openapi.etsy.com (заголовок `x-api-key` у форматі `keystring:shared_secret`, так вимагає документація Etsy).
5. Не впевнений: чи ключ запрацює одразу, чи після схвалення Etsy («pending approval»), і які ліміти запитів дадуть.

**Що API покаже (перевірено за офіційною специфікацією Etsy):**
- по магазину: загальна кількість продажів за весь час, кількість активних лістингів, «улюблені», кількість і середня оцінка відгуків, країна, чи у відпустці
- пошук активних лістингів за ключовими словами: назва, теги, ціна, «улюблені», категорія, матеріали, чи персоналізується
- перегляди лістингу — лише окремим запитом по кожному лістингу (getListing / getListingsByListingIds); у результатах пошуку їх немає; оновлюються раз на добу (перевірено за специфікацією 12.11.2026)
- щомісячний приріст продажів магазину — бот рахує сам як різницю між двома знімками

**Що API НЕ покаже:**
- готовий рейтинг «топ-10 усього Etsy» — потрібен стартовий список магазинів (наприклад, 20–30 лідерів ваших ніш)
- виторг у доларах, конверсію, рекламу, трафік чужих магазинів
- обсяги пошуку з Marketplace Insights
- продажі за минулі місяці — відлік почнеться з першого знімка

## GOOGLE ADS / KEYWORD PLANNER — що реально (не впроваджено)
**Технічно можливо, але складно:**
- з 09.09.2026 доступ до Google Ads API прив'язаний до проєкту в Google Cloud, а не до developer token 🟡
- для дослідження ключових слів (KeywordPlanIdeaService) потрібен рівень доступу Basic або вищий; на початковому рівні Explorer частина функцій обмежена 🟡
- Google визнавав черги з розгляду заявок на доступ і помилки авторизації після переходу 🔴
- потрібен OAuth-доступ до твого акаунта (client ID, secret, refresh token). Його токени живуть ~1 годину й оновлюються — захищена форма бота під такий тип ключів не підходить. Тобто секрети довелося б зберігати прямо в сесії — не раджу
- не впевнений: чи API покаже точні обсяги пошуку, чи діапазони (в інтерфейсі без активної реклами — діапазони)

**Що від тебе, якщо все ж підключати:** проєкт у Google Cloud, увімкнений Google Ads API, заявка на рівень Basic, OAuth-клієнт, ID акаунта Google Ads.

**Простий робочий варіант (рекомендую):** під кожен випуск ти або менеджер вивантажує з Keyword Planner CSV по 5–10 темам випуску (Tools → Keyword Planner → Discover new keywords → Download) у Drive-папку бота. 5 хвилин, без ризиків для акаунта.

## SERPAPI (Google Trends через API) — ціни
За даними агрегаторів (на сайті SerpApi не перевіряв) 🟡:
- безкоштовно — 250 запитів на місяць
- Starter — $25/міс за 1 000 запитів
- Developer — $75/міс за 5 000
- Production — $150/міс за 15 000
- оплата лише помісячна, без «плати за запит»
Не впевнений, скільки «запитів» списує один запит до Google Trends. Для точкових перевірок під випуск (5–10 запитів) вистачило б безкоштовного тарифу.
